# Cosmos KP Builder

Внутренний инструмент отдела продаж Cosmos Black Sea для подготовки коммерческих предложений по гостиничным номерам.

## Запуск

```bash
pnpm install
pnpm dev
```

Проверки проекта:

```bash
pnpm typecheck
pnpm build
```

## Структура

- `app/page.tsx` — стартовая страница и четыре этапа сценария.
- `app/components/` — интерактивные компоненты интерфейса.
- `app/data/` — типы и временный источник данных о лотах.
- `app/globals.css` — Tailwind CSS и стили визуальной системы.

Проект не содержит финансовых формул, клиентских данных, PDF, backend или базы данных.
